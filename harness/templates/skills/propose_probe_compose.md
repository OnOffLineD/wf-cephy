# Propose–Probe–Compose Workflow Protocol (Harness² Standard)

복잡한 문제 해결, 기능 구현, 리팩토링 시 아래 3단계 자가 치유 루프를 순차 수행합니다.

## Phase 1. Propose (가설 및 후보안 수립)
1. 문제의 본질(실패한 테스트, 에러 로그, 요구사항)을 핀포인트로 식별합니다.
2. 부작용을 최소화할 수 있는 외과적 수정 후보(1~2개)를 구체화합니다.
3. 임의의 직관에 의존하지 않고, 검증 가능한 측정 기준(테스트 통과, 정적 분석, 스키마 일치)을 명시합니다.

## Phase 2. Probe (격리 검증 및 스모크 테스트)
1. 후보안을 코드에 외과적으로 적용합니다.
2. 표준 프로브 스크립트를 즉시 실행합니다:
   ```bash
   python scripts/probe.py    # Python 프로젝트
   node scripts/probe.mjs     # Node/TS 프로젝트
   ```
3. 3대 게이트(단위/통합 테스트, 도메인 정합성 스모크, 지식 그래프/빌드)의 출력과 종료 코드를 확인합니다.
4. 실패 시 트레이스백을 분석하여 가설을 수정하고 재실행합니다.

## Phase 3. Compose (최적안 채택 및 지식 누적)
1. 모든 게이트를 통과한 검증된 변경사항만 작업 브랜치에 확정(Commit)합니다.
2. 새로 발견된 예외 케이스 및 해결 패턴은 `EXPERIENCE.md`에 규격화하여 기록합니다.
3. 지식 그래프를 동기화(`graphify update .`)하고 `PROGRESS.md`를 갱신합니다.
