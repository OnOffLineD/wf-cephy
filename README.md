# 🌌 WF-Cephy (세피 데스크톱 어시스턴트)

> **워프레임(Warframe) 인게임 모딩 진단 & 데스크톱 컴패니언 어시스턴트**  
> 인게임 스크린샷 OCR을 통한 무기/모딩 자동 진단, 정밀 데미지 계산 엔진, 실시간 월드 이벤트 트래커, 그리고 귀여운 AI 비서 **세피(Cephy)**를 제공합니다.

---

## 🌟 주요 기능

### 1. 🔍 스크린샷 모딩 OCR 진단 & 데미지 엔진
- **단축키 원클릭 진단 (`Alt + Q`)**: 게임 중 모딩 화면을 즉시 캡처하고 무기 및 장착 모드, 랭크를 자동으로 판독합니다.
- **정밀 수학 엔진**: 단순 모드 나열을 넘어 **버스트 DPS, 지속 DPS, 치명타 티어별 가중 배수, 상한/하한 치명타 데미지, 속성 합성**을 정밀 계산하여 브리핑합니다.
- **리벤(Riven) 옵션 진단**: 긍정/부정 옵션의 롤 상태와 기존 빌드 대비 성능 변화를 비교 분석합니다.

### 2. 🤖 지능형 AI 비서 세피(Cephy) 3-Tier 채팅
- **Level 1 (스몰톡/일상 대화)**: 위트 있고 다정한 성격의 세피와 자유롭게 대화합니다.
- **Level 2 (인게임 공략 & 파밍 가이드)**: 보스 공략, 속성 상성, 드롭 테이블(`drops_all.json`) 및 위키 공략 문서를 실시간 검색(BM25/RAG)하여 실전 가이드를 제공합니다.
- **Level 3 (모딩 리포트)**: OCR 진단 결과를 시각화된 리포트로 요약 출력합니다.

### 3. ⏰ 실시간 월드 이벤트 & 숙제 체크리스트
- **월드 이벤트 트래커**: 시터스 낮/밤, 포르투나 온도, 데이모스 주기, 출격(Sortie), 아콘 토벌전 주기를 실시간으로 확인합니다.
- **스마트 체크리스트**: 일일/주간 숙제를 클릭 한 번으로 체크하고, 자동 리셋 주기를 관리합니다. 대화창에서 *"오늘 출격 끝났어"*와 같은 자연어로도 완료 처리할 수 있습니다.

### 4. 🪟 플로팅 데스크톱 펫
- 화면 우측 하단에 상주하는 반투명 세피 펫이 상태에 따라 다양한 표정과 애니메이션(기본, 행복, 생각, 글리치)을 보여줍니다.
- 클릭 및 드래그, 말풍선 알림 기능을 지원합니다.

## 🚀 빠른 시작 (Quick Start)

### 사전 요구사항
- **OS**: Windows 10 / 11 (64-bit)
- **Python**: Python 3.10 이상 권장
- **OCR 런타임**: Windows 기본 OCR (한국어/영어 언어 팩 설치 권장)

### 1. 저장소 클론 및 패키지 설치
```bash
git clone https://github.com/OnOffLineD/wf-cephy.git
cd wf-cephy

# 가상환경 생성 (권장)
python -m venv venv
venv\Scripts\activate

# 필수 의존성 설치
pip install -r requirements.txt
```

### 2. 실행
#### 💡 원클릭 실행 (배치 파일)
```bash
# 데스크톱 컴패니언 실행 (GUI 모드)
start_companion.bat
```

#### 🐍 직접 실행
```bash
python main_companion.py
```

## ⚙️ 환경 설정

필요한 경우 루트의 `.env.example`을 복사하여 `.env`를 생성하고 경로를 커스터마이징할 수 있습니다:

```ini
# 사용자 런타임 데이터 저장 경로 (기본값: ./data)
WF_USER_DATA_DIR=./data

# 윈도우 터미널 UTF-8 강제
PYTHONIOENCODING=utf-8
```

## 📁 프로젝트 구조

```text
wf-cephy/
├── start_companion.bat     # 데스크톱 컴패니언 원클릭 실행기
├── main_companion.py       # 앱 메인 엔트리포인트 (펫 + UI + 오케스트레이터)
├── requirements.txt        # 파이썬 의존성 목록
├── .env.example            # 환경변수 설정 예시
├── assets/                 # 캐릭터 스프라이트, UI 아이콘, 효과음
├── data/                   # 정규화 DB(wf_database.sqlite), 카탈로그, 페르소나 설정
├── models/                 # YOLOv8 슬롯 탐지 모델 (slot_detector.onnx)
├── rules/                  # 데미지 공식, 위키 공략 문서(wiki_docs)
├── scripts/                # 핵심 로직 모듈 (데미지 엔진, OCR, 트래커, UI 뷰)
└── tests/                  # 단위 및 통합 테스트 슈트
```
