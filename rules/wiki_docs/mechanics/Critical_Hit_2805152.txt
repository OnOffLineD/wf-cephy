# 치명타 시스템 및 치명타 티어 완벽 가이드 (Critical Hit)

## 1. 치명타 티어 (노란 크리 / 주황 크리 / 빨강 크리)
- 치명타 확률(Critical Chance)이 **100%를 초과**해도 버려지지 않고 **상위 치명타 티어**로 승급하여 치명타 배수가 중첩 적용됩니다!
  - **1티어 (노란색 숫자, 1% ~ 100%)**: `1 + (치명타 배수 - 1)`
  - **2티어 (주황색 숫자, 101% ~ 200%)**: `1 + 2 × (치명타 배수 - 1)`
  - **3티어 (빨간색 숫자, 201% ~ 300%)**: `1 + 3 × (치명타 배수 - 1)`
  - **4티어 이상 (빨간색 숫자 + 느낌표 `!`, `!!`, `!!!`, 301% 이상)**: 티어당 `(치명타 배수 - 1)`이 계속 합연산으로 추가됩니다.
- **헤드샷 치명타 보너스 (Headshot Crit)**:
  - 치명타가 적의 머리(약점)에 적중하면, 일반 헤드샷 배수(3배)에 더해 **추가로 2배의 치명타 헤드샷 배수가 곱연산**되어 총 **6배 이상의 폭발적인 데미지**가 들어갑니다!

## 2. 상대적 치명타(곱연산) vs 절대적 치명타(합연산)
1. **상대적 치명타 확률 (Modded / Multiplicative)**:
   - `포인트 스트라이크`, `크리티컬 딜레이`, `크리핑 불즈아이`, `블러드 러시(연속기 비례)` 등 일반 모드는 무기의 **기본 치명타 확률에 곱연산**됩니다.
   - 공식: `기본 치명타 확률 × (1 + 모드 치명타 확률 합계)`
2. **절대적 치명타 확률 (Flat / Additive - 최종 합연산)**:
   - 모든 모드 계산이 끝난 뒤 **맨 마지막에 고정 수치(+%)로 그냥 더해지는 사기적인 버프**들입니다. 기본 치명타 확률이 5%밖에 안 되는 무기(예: 쿠바 뉴코어, 스포어레이서 등)도 단숨에 치명타 무기로 만들어 줍니다!
   - **대표적인 절대적 치명타 버프**:
     - **아케인 어벤저 (Arcane Avenger)**: 피격 시 최종 치명타 확률 **+45%**
     - **관통 (Puncture) 상태이상**: 적에게 걸린 관통 5스택 시 최종 치명타 확률 **+25%**
     - **해로우 4번 (커버넌트)**: 최종 치명타 확률 최대 **+50% (헤드샷 시 +200%)**
     - **시트린 4번 (크리스탈라이즈)**: 수정 타격 시 치명타 확률 **300% (빨강 크리 확정)** 고정
     - **쿨레르보 1번 (래스풀 어드밴스)**: 근접 무기 최종 치명타 확률 수백 % 고정 추가
     - **아다르자 카밧 (캣츠 아이)**: 최종 치명타 확률 **+60%**

## 3. 치명타 배수 (Critical Multiplier) 강화 수단
- **냉기 (Cold) 상태이상**: 적에게 냉기 10스택(빙결) 시 최종 치명타 배수 **+1.0x** 추가 (일반 9스택 시 +0.5x).
- **강화 유대 (Tenacious Bond - 동반자 모드)**: 동반자의 치명타 확률이 50% 이상일 때 플레이어의 모든 무기 최종 치명타 배수 **+1.2x** 상시 추가! (불파파일라/하운드/센티넬 무기에 치명타 모드를 끼워 50%를 넘기면 상시 발동)
