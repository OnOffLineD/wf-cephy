# 워프레임 인게임 설정 추천 가이드 (공식 한글 설정 명칭 기준)

> 모든 항목명은 인게임 [설정] 메뉴의 DE 공식 한글 표기를 그대로 사용합니다. 메뉴 위치는 패치에 따라 탭이 바뀔 수 있으니, 설정 화면 상단 검색창에 항목명을 그대로 입력해 찾는 것이 가장 빠릅니다.

## 1. 조작 설정 (오토파이어 / 연속 발사 / 달리기)
- **'발사 버튼 유지 시 연속 발사'**: 켜기 권장. 흔히 '오토파이어', '연속발사'라고 부르는 설정으로, 반자동 무기도 발사 버튼을 누르고 있으면 계속 쏩니다. 손목 피로를 크게 줄여 줍니다.
- **'근접 공격 시 카메라 회전'**: 끄기 권장. 켜 두면 근접 콤보 중 카메라가 멋대로 돌아가 방향 감각을 잃기 쉽습니다.
- **'달리기 전환'**: 켜기 권장. 달리기 키를 계속 누르지 않아도 한 번 눌러 달리기 상태를 유지합니다.
- **불릿 점프 단축키 팁**: 불릿 점프는 '웅크리기(슬라이드) 중 점프'입니다. 웅크리기 키를 마우스 옆 버튼 등 누르기 편한 키로 옮기면 이동 속도가 크게 좋아집니다.

## 2. 화면 설정 (시야각 / 피해 수치 / 흔들림)
- **'시야각(FOV)'**: 90 권장. 너무 낮으면 시야가 좁아 적과 아군 위치를 놓치고, 너무 높으면 화면 가장자리가 왜곡됩니다.
- **'피해 수치'**: 압축(콤팩트) 표기 권장. 강철의 길처럼 큰 숫자가 뜨는 구간에서 1.2M처럼 짧게 표시되어 화면이 덜 지저분합니다.
- **'화면 흔들림'**: 끄기 권장. 폭발 무기 사용 시 화면이 계속 흔들리는 것을 막아 멀미를 줄입니다.
- **'모션 블러'**: 끄기 권장. 빠른 이동 중 화면 번짐이 사라져 시인성이 좋아집니다.
- **'테두리 없는 창 모드'**: 권장. 알트탭으로 웹 검색이나 도우미 앱을 오갈 때 화면 깜빡임 없이 전환됩니다.

## 3. 접근성 설정 (적 하이라이트 / 아군 하이라이트 / 시각 효과)
- **'적 하이라이트'**: 켜기 권장. 적 외곽선 색상을 눈에 띄는 색(예: 빨강, 주황)으로 지정하면 어두운 타일셋에서도 적을 바로 찾을 수 있습니다.
- **'아군 하이라이트'**: 적 하이라이트와 겹치지 않는 색(예: 파랑, 초록)으로 지정해 오사격 판단과 분대원 위치 파악을 돕습니다.
- **'팀원의 시각 효과 줄이기'**: 켜기 권장. 분대원의 어빌리티 이펙트가 화면을 덮는 현상을 줄여 내 캐릭터와 적이 잘 보입니다.

## 4. HUD 설정 (분대원 상태창 / 미니맵)
- **'분대원 상태창 상시 표시'**: 켜기 권장. 분대원의 체력·실드 상태를 항상 확인할 수 있어 부활이나 지원 타이밍을 놓치지 않습니다.
- **'미니맵 회전 고정'**: 켜기 권장. 미니맵이 캐릭터 방향을 따라 돌지 않고 북쪽 기준으로 고정되어 길 찾기가 쉬워집니다.

## 5. 요약 체크리스트
- 켜기: 발사 버튼 유지 시 연속 발사, 달리기 전환, 적 하이라이트, 아군 하이라이트, 팀원의 시각 효과 줄이기, 분대원 상태창 상시 표시, 미니맵 회전 고정
- 끄기: 근접 공격 시 카메라 회전, 화면 흔들림, 모션 블러
- 값 지정: 시야각(FOV) 90, 피해 수치 압축(콤팩트) 표기, 테두리 없는 창 모드
